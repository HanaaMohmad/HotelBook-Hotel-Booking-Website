HOTELBOOK — Updated with real stock photos and video

Run it:
1. Extract the ZIP completely.
2. Keep index.html, style.css, script.js, and assets/ together.
3. Open index.html in Chrome or Edge.

What's updated:
- Hotel and destination images now use real photography from Unsplash.
- Added a playable real resort stock video from Pexels in a dedicated section.
- The Pexels video source link is shown on the page.
- Existing responsive layout, destination search, and demo booking modal remain.

Internet required:
The real photos and video load from Unsplash and Pexels, so an internet connection is needed for this media. If a video does not start, open the Pexels source link in the video section.

Note: hotel names, prices, ratings, sign-in and booking are sample UI only. The site does not create real reservations or process payments.
